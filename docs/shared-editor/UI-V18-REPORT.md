# UI/UX Editor รุ่น 18

ทำงานบน Repository game-editor-preview, branch development/shared-editor-adapters ไม่มี Commit/Push/Deploy

## สิ่งที่แก้

- ช่องวิชาและระดับชั้นใช้สีเทาอ่อน ตัวอักษรเทาเข้มและล็อกเหมือนกันทุกเกม แก้ CSS specificity ที่ทำให้ช่องยังมีพื้นขาวและกรอบม่วง ไม่เปลี่ยนการอ่านข้อมูล
- ลบหมายเหตุบนการ์ดทั้งเกมพร้อมใช้และเกมที่ยังพัฒนา ปุ่มที่ไม่ผ่านยัง disabled และเขียน “⚙️ กำลังพัฒนา” ไม่เปิดปุ่มด้วยการเปลี่ยนสี
- ใช้ข้อความข้อจำกัดภาษาไทยร่วมกันในแท็บข้อมูลและภารกิจ ไม่แสดง bundle.note ที่มีรายละเอียดโปรแกรม แต่เก็บข้อจำกัดและ validation เดิมครบ
- Career Quest แสดงชื่อช่องชื่อด่าน/คำถามชัดเจน แปลชื่อภาพในรายการเลือกเป็นไทยและตั้งชื่อภาพในแกลเลอรี อ่านง่ายขึ้นโดย option value และ asset key ไม่เปลี่ยน

## Career Quest: ขอบเขตที่ตรวจ

ต้นฉบับเทียบคำตอบกับชื่ออาชีพใน choices โดยตรง ด่านแรกใช้ชื่ออาชีพสร้างคีย์ภาพ ด่านสองจับคู่อุปกรณ์กับอาชีพ ด่านสามจับคู่สถานที่และคำถามกับอาชีพและตัดตัวลวงบางตัวออก จึงไม่เปิดให้กรอกชื่ออาชีพอิสระ เพราะจะทำให้ภาพ ตัวลวง และคะแนนไม่สอดคล้องกัน

ปรับชื่อด่าน คำแนะนำ ข้อความด่าน คำถามสถานที่ 10 ข้อ ภาพและเฉลยที่เลือกจากอาชีพเดิมได้ รูปแบบสามด่าน ด่านละสิบข้อคงเดิม คำถามอัตโนมัติของด่าน 1–2 ยังคงรูปแบบเดิม รอบนี้ไม่ได้เพิ่มการเปลี่ยนชื่ออาชีพอิสระหรือแก้ engine

## ผลทดสอบใหม่

- ตรวจ schema/SHA256 ของเกมทั้งหมด31เกม: ผ่าน เปิดปุ่มตามหลักฐาน29เกม
- UI เปิด Editor29เกม, สองบริบทเบราว์เซอร์, reset/close, เปลี่ยนและคืนภาพ, 10ครั้งสลับแท็บ: ผ่าน ไม่มี JS error/native dialog/คำขอเขียนส่วนกลาง
- ตรวจ computed style ยืนยัน read-only พื้นเทา parent rgb(242,243,245), inputโปร่งใส border0 และตัวอักษร rgb(69,75,85)
- viewport 1440×1000,768×1024,375×812,320×568,844×390: ผ่าน ไม่มี horizontal overflow ส่วนหัว/ท้ายอยู่ในตำแหน่งเดิม
- หน้าการ์ด31เกม:29ปุ่มพร้อมใช้,2ปุ่มกำลังพัฒนา,ไม่มีข้อความสถานะเทคนิคใต้การ์ด
- Career Quest: เล่นครบ30ข้อบน native engine ทั้ง Preview และ ZIP ตรวจCRCและเล่นแบบบล็อกเครือข่ายภายนอก คะแนน29/30ตรงกัน (จงใจตอบผิด1ข้อ), MediaPipeจริงกับกล้องจำลอง ไม่ใช่ทดสอบมือจริง
- Prompt regression:31เกมทดสอบด้วยข้อมูลจำลอง,clipboard/reset/mobileผ่าน ตัวสร้าง Prompt ไม่เปลี่ยน โค้ด app.js เปลี่ยนเฉพาะการ์ด Editor

## สถานะและงานค้าง

รองรับตามขอบเขตที่เปิดแก้29/31เกม ไม่ได้ทดสอบ gameplayทั้ง29ซ้ำรอบนี้ ใช้หลักฐานรายเกมเดิมร่วมกับ UI regression ใหม่ และทดสอบ Career Quest ใหม่ครบ

- Animals (native-25): Previewครบ5ระดับ แต่ ZIPทดสอบ inference timeout จึงปิดปุ่ม
- Anatomy (native-28): ยังไม่ผ่านลำดับจบภารกิจสแกนและไปด่านถัดไปครบ จึงปิดปุ่ม
- กล้อง มือจริง มือถือ/แท็บเล็ตจริง และเว็บไซต์ที่ deployจริงยังไม่ได้ทดสอบ ใช้ Chrome headless+viewport/fakecamera กล้องใช้งานต้องHTTPSหรือlocalhostและอนุญาตกล้อง

ตารางครบ31เกมอยู่ REPORT.md และsupport-status.json เดิม คะแนน/ZIPของเกมอื่นอ้างหลักฐานในevidence/ ไม่อ้างว่ารันทุกเกมใหม่
