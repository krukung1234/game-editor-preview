## ขอบเขตการทดสอบ

- หลักฐานใหม่แยกรายเกมใน evidence/ และ support-status.json; Mini City และเกม 15/16/18/30 มีผลทดสอบจากรอบก่อน ไม่อ้างว่ารันทดสอบเก่าทั้งหมดใหม่แล้ว
- ใช้ Chrome จริง โหลด SDK/WASM/โมเดลจริงด้วยกล้องจำลอง ทดสอบคำตอบถูก/ผิดหรือเงื่อนไขจบด่านตามหลักฐานแต่ละเกม อินพุต Canvas/ลากวางบางส่วนส่งผ่าน callback เดิมโดยใช้วัตถุ/พิกัดจริง ห้ามตีความว่าได้ทดสอบท่ามือของคนจริงแล้ว
- Editor แก้ชื่อและข้อมูลที่รองรับผ่าน UI โดยวิชาและระดับชั้นเป็นข้อมูลต้นฉบับอ่านอย่างเดียว จากนั้น Preview บน native engine เดิม ดาวน์โหลด ZIP ตรวจ CRC แตกไฟล์ และเล่นซ้ำบน localhost โดยบล็อกเว็บไซต์ภายนอกและห้ามยืมไฟล์จาก games/
- เกมเขาวงกตไม่มี AR ในต้นฉบับ ทดสอบคำสั่งเดิน/หมุน/เก็บชีสครบ 20 ด่านและดาว/คะแนน ไม่เพิ่มกล้องหรือเปลี่ยนกติกา
- รูป sprite ต้องจัดช่องตามรูปต้นฉบับ ข้อความที่ฝังในรูปเปลี่ยนด้วยการอัปโหลดรูปใหม่เท่านั้น ภาพพื้นหลังใหม่ไม่ย้ายพิกัด hit target ดั้งเดิม
- กล้องต้องใช้ HTTPS หรือ localhost และได้รับอนุญาต เปิด file:// อาจเล่นแบบเมาส์ได้เฉพาะเกมที่รองรับ ห้ามรับรองกล้อง AR แบบดับเบิลคลิกไฟล์ทุกเบราว์เซอร์; เสียงพูดบางภาษาอาศัยเสียงของระบบ

## การแก้โค้ดในรอบนี้

- Composer รองรับ repair ที่อ้างตำแหน่ง AST และ SHA ของต้นฉบับชัดเจน รวมลำดับสคริปต์และการสังเกตผล inference โดยคง engine เดิม
- แก้ SDK Tasks Vision / Face Detection ที่อ้างรุ่นไม่มีอยู่จริงเฉพาะฉบับส่วนตัวและการแพ็ก ZIP
- แก้การวางอาหารให้ครบจำนวน รักษาระยะห่างและขนาดเดิม พร้อมพื้นที่เล่นขั้นต่ำที่สเกลตามหน้าจอ
- แก้ต้นฉบับ Anatomy ที่ใช้ตัวแปรก่อนประกาศ และ Sudoku ข้อมูลโจทย์ที่ขัดเฉลยเฉพาะ Adapter; ยังไม่เปิดหากผลทดสอบไม่ครบ
- Serialize การเริ่ม SDK หลายตัว และรอ send ที่กำลังทำงานก่อนปิด SDK; หยุดกล้องก่อนถอด Preview
- รองรับ UTF-8 BOM ตรวจ SHA ให้ตรงกับ Response.text และเพิ่ม pointer/keyboard fallback ให้คำตรงข้ามไทยผ่านฟังก์ชันตอบเดิม

ใช้ Editor กลางเดิม 3 แท็บและ 3 ปุ่ม ไม่มีบันทึกหรือร่างถาวร วิชา/ระดับชั้นอ่านอย่างเดียว มีเมนูข้ามข้อและก่อนหน้า/ถัดไป คำถามแบบเลือกคำตอบใช้ radio หรือ checkbox ตามกติกา คืนค่า/ปิด/ลบใช้ modal เดียวกันพร้อม focus และยกเลิกได้ แกลเลอรีภาพแยกหมวด แสดงครั้งละ 12 ภาพ เปลี่ยนและคืนภาพต้นฉบับได้

- EDITOR-COMPLETE-UI.json: ตรวจ 29 Editor, 5 viewport, 10 ครั้งสลับแท็บ, ผู้ใช้สองคน, อัปโหลด/คืนภาพ, reset/close; ไม่มี JavaScript error, native dialog หรือคำขอเขียนส่วนกลาง
- EDITOR-COMPLETE-MINI-CITY.json: เล่นครบห้าด่านทั้ง Preview/ZIP ตรวจคะแนนและข้อมูล/ฉากใหม่ ZIP 78 ไฟล์ประมาณ 103 MB รวมโมเดล AR ที่จำเป็น ไม่ใช่แค่ตัวเปิดเว็บ
- Prompt unit regression: 20 ข้อความเก่าและ 9 กรณีรักษาคำสั่งที่ถูกต้องผ่าน ไม่แก้ js/app.js ในรอบ Editor นี้
- รูป PNG/JPEG/WebP จำกัด 750 KB ต่อภาพ และ 12 MB รวม ตรวจ decode จริง ไม่บีบอัด sprite อัตโนมัติเพราะทำให้พิกัดช่องเดิมเสียได้ ควรเตรียมภาพตามสัดส่วนต้นฉบับ
- กล้อง/มือจริงและโทรศัพท์จริงยังไม่ได้ทดสอบ ไม่ได้ deploy ไป Pages

เกม 25 Animals: Preview ผ่านครบห้าระดับ แต่ ZIP รอเฟรม inference แล้ว timeout จึงยังปิดปุ่ม ไม่ถือว่าผ่าน ZIP
เกม 28 Anatomy: พบเฉลยต้นฉบับเป็นตัวเลข 0/1 ปรับการแปลงเป็น boolean ใน Working Copy และกลับเป็น 0/1 ใน native binding; ยังปิดปุ่มจนกว่าจะผ่านครบ
