## ผลตรวจ

- Editor 31/31: เปิด แก้ชื่อและข้อมูลภายในเกม คืนค่า ปิดได้ ตรวจ responsive ที่ 1440×1000, 768×1024, 375×812 ไม่มีแถบเลื่อนแนวนอน

- ZIP 31/31: ดาวน์โหลด ตรวจ CRC แตกไฟล์ เปิดด้วย HTTP ใน browser context ใหม่ที่ไม่ได้ล็อกอิน และบล็อกเครือข่ายภายนอก ตรวจข้อมูลที่แก้ใน native binding อีกครั้ง ไม่พบ JavaScript pageerror ในขั้นตอนโหลดนี้ ไม่ใช่หลักฐานว่ากล้องทุกเกมทำงานออฟไลน์ได้

- Unit/gate 8/8; Rules และการแยก Production ดู test-results/spark-rules.json และ preflight-production.json
- ANATOMY LAB: ไฟล์ games/AR_ANATOMY_LAB_A01/index.html ในเว็บไซต์หลักและ Adapter native-28.json ตรงกัน ตัวตรวจยืนยันเปลี่ยนเพียงลำดับ script blocks เนื้อหาแต่ละบล็อกและ HTML/CSS เดิมไม่เปลี่ยน ทรัพยากรอีก 517 ไฟล์มี hash เดิม
- หลักฐาน Anatomy เดิม: โหลดภาพ 87 รายการ ไม่มีภาพหาย ทดสอบ callback เล่น 5 ภารกิจ คะแนน 7/5/5/5/4 รวม26 ทั้ง Preview และ ZIP ซึ่งเป็นการจำลอง ไม่ใช่มือจริง

## ขอบเขตผลผ่าน

การทดสอบรอบนี้ตรวจ Editor/Preview/ZIP ครบ31เกม โดยแก้ข้อมูลตัวแทนหนึ่งรายการต่อเกม ไม่ได้เปลี่ยนทุกช่องทุกภาพในทุกเกม และไม่ได้เล่นทุกด่านด้วยคนบนอุปกรณ์จริง หลักฐาน gameplay จำลองก่อนหน้าคงอยู่ docs/shared-editor/evidence และรายงาน preflight; ไม่ตีความว่าเป็นการผ่านกล้องหรือทุกด่านบน iPhone/Android

ทดสอบสมาชิกยืนยันอีเมลด้วยลิงก์จำลอง ไม่ได้ส่งอีเมลเข้ากล่องจริง Production ยัง disabled ไม่ได้ตรวจแผนใน Console สด การตั้งค่าที่รวมมีเฉพาะ Spark Auth/Firestore ไม่เปิด Functions/Storage/Gateway ไม่มีการใช้ Billing

รอบเริ่มต้นตัวทดสอบทั่วไปไม่รองรับตาราง Sudoku จึงเพิ่มกรณีทดสอบเฉพาะตาราง อีกกรณีข้อมูลจำลอง Admin ขาด approvedBy ทำให้ Rules ปฏิเสธอย่างถูกต้อง จึงแก้ fixture ให้ตรงกับ schema สมัครจริง ไม่มีการผ่อน Security Rules เพื่อให้ทดสอบผ่าน

## งานที่เหลือและความพร้อม

พร้อมนำชุดไฟล์เข้าสู่ขั้นทดสอบอุปกรณ์จริง ยังไม่พร้อมรับรองเปิด Production ต้องตรวจ Android Chrome, iPhone Safari และ Windows Chrome กล้อง/มือจริง ทุกด่าน คะแนน/โบนัส เสียง สิทธิ์กล้อง การแตะสำรอง การหมุนจอและสลับแท็บ ตาม CSV 31 เกมที่แนบ บางเกมใช้กล้องพื้นหลังกับเมาส์เท่านั้น ไม่ใช้ Hand Tracking ให้บันทึกไม่เกี่ยวข้อง

HTTPS สำหรับโทรศัพท์และการเชื่อม Firebase จริงต้องได้รับอนุญาตก่อน คง UID Admin เดิมผ่านทะเบียน Console เท่านั้น ไม่อนุมัติตัวเองจากเว็บ ทดสอบยืนยันอีเมลจริงและ quota ภายหลัง โปรเจกต์เก่าไม่เปลี่ยนแปลง

GitHub Pages เผยแพร่ไฟล์สาธารณะ ผู้รู้ URL ตรงยังเข้าถึงเกมได้ ระบบนี้ไม่ได้ป้องกันไฟล์เกมสมบูรณ์ ชุดดาวน์โหลดส่วนตัวไม่มีระบบสมาชิกและเปิดแยกได้ตามสภาพแวดล้อม กล้องอาจต้องใช้ HTTPS/localhost และบางทรัพยากร AR ยังต้องใช้อินเทอร์เน็ต
