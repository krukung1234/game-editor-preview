# ทดสอบ Android จริงผ่าน HTTPS ส่วนตัว — V21 Spark

รอบแรก: **AR Word Quest — เกมคำศัพท์ภาษาอังกฤษ** (`games/ar-words-english/index.html`) บน `test-v21-spark` ใช้ไฟล์เกมจริงโดยไม่แก้โค้ด ไม่เปิดเว็บไซต์หลัก/Editor/Admin และไม่เชื่อมระบบสมาชิก Firebase รอบนี้จึงทดสอบกล้อง มือ เสียงและเกม ไม่ใช่ทดสอบการสมัครสมาชิกบนมือถือ

เกมรุ่นที่อยู่ใน Repository นี้สุ่มเล่น **20 ข้อ ตัวเลือก2ภาพ** ใช้นิ้วชี้ค้างเพื่อเลือก ไม่ใช่เกม3ด่านหรือการจีบนิ้ว หลังตอบถูกมีช่วงรับเหรียญ/กล่อง3ครั้ง ตอบถูกต่อเนื่อง3ข้อมีของพิเศษ ตามกลไกที่เขียนอยู่จริง

## วิธีที่เลือกและค่าใช้จ่าย

ใช้ **Tailscale Personal ฟรี + Tailscale Serve** เชื่อมคอมพิวเตอร์กับโทรศัพท์ของคุณผ่านเครือข่ายส่วนตัว หน้าเว็บเป็นHTTPSที่มีcertificateปกติ ไม่ต้องเปิด Firebase Blaze ไม่ใช้ Functions, Storage, Gateway ไม่ Deploy GitHub Pages ไม่ต้องเปิดพอร์ตเราเตอร์หรือพอร์ต8096ให้LAN

Serve จำกัดการเข้าถึงภายในtailnet ส่วน Funnel เป็นการเปิดอินเทอร์เน็ตสาธารณะ **งานนี้ใช้เฉพาะ Serve** เครื่องมือยังตรวจชื่อบัญชีTailscaleให้ตรงกับที่คุณกรอก ถ้าไม่มีidentity header เช่นคำขอสาธารณะจากFunnel จะตอบ403 ไม่บันทึกชื่อบัญชีลงไฟล์หรือlog ไม่ต้องกรอกรหัสผ่านFirebaseหรือรหัสVIP

ใช้เครือข่ายPersonalของคุณที่มีเฉพาะอุปกรณ์ที่คุณควบคุมสำหรับรอบนี้ ไม่แชร์เครื่องให้ผู้ใช้อื่น ไม่ตั้งexit node/subnet router ถ้าบัญชีเสนอแผนทดลองแบบเสียเงินให้เลือกPersonalฟรี ไม่ผูกบัตรหรือเปิดแพ็กเกจเสียเงิน

แหล่งข้อมูลทางการที่ตรวจวันที่18ตุลาคม2026:
- [Tailscale Serve และ identity headers](https://tailscale.com/docs/features/tailscale-serve)
- [Personal plan ฟรี](https://tailscale.com/docs/account/manage-plans/free-plans-discounts)
- [คำสั่ง Serve และปิดบริการ](https://tailscale.com/docs/reference/tailscale-cli/serve)
- [HTTPS และ certificate transparency](https://tailscale.com/docs/how-to/set-up-https-certificates)

## 1. เตรียม Windows และ Android

1. ติดตั้งNode.js22บนWindowsถ้ายังไม่มี เปิดPowerShellแล้วตรวจ `node --version`
2. ดาวน์โหลดTailscaleสำหรับWindowsจาก [เว็บไซต์ทางการ](https://tailscale.com/download) และติดตั้งด้วยตัวเอง เปิดแอปแล้วเข้าสู่ระบบบัญชีPersonalของคุณ
3. บนAndroidติดตั้งแอปTailscaleจากลิงก์Androidในเว็บไซต์ทางการเดียวกัน เข้าสู่ระบบ**บัญชีเดียวกับWindows** และอนุญาตการเชื่อมต่อVPNของTailscale เปิดให้เชื่อมต่อทั้งสองเครื่อง
4. ในTailscale Consoleตรวจว่ามีWindowsและAndroidของคุณอยู่ในเครือข่ายเดียวกัน ไม่ใช้เครื่องที่ติดtagสำหรับการทดสอบนี้ เพราะServeไม่ส่งuser identityจากอุปกรณ์tagged
5. ตั้งชื่อเครื่องWindowsในTailscaleแบบไม่ใส่ข้อมูลส่วนตัว เช่น `ar-test-pc` ก่อนเปิดHTTPS ชื่อโดเมนcertificateอาจปรากฏในpublic certificate transparency log แต่ไฟล์เกมยังจำกัดการเข้าผ่านtailnet ไม่ใช้ชื่อ/อีเมลสมาชิกเป็นชื่อเครื่อง
6. โทรศัพท์ใช้Chromeปกติรุ่นล่าสุดที่ติดตั้งได้ อย่าเปิดเกมในbrowserภายในFacebook/LINE ทั้งPCและมือถือควรมีอินเทอร์เน็ตเพื่อโหลดMediaPipe/WASM/โมเดลมือจากCDN และโมเดลสาธารณะ ไม่ใช่การเปิดFirebase Storageของโปรเจกต์

เครื่องนี้ยังไม่ได้ติดตั้ง/ลงชื่อเข้าTailscaleตอนจัดเตรียม จึงยังไม่มีURLจริง และไม่ได้ออกcertificateหรือตั้งเครือข่ายแทนเจ้าของ

## 2. เปิดเซิร์ฟเวอร์เกมบน Windows — หน้าต่างที่1

เปิดPowerShellแล้วรันทีละบรรทัด:

```powershell
cd D:\game-editor-preview
git branch --show-current
```

ต้องแสดง `test-v21-spark` ถ้าเป็นbranchอื่นให้หยุด อย่าสลับbranchขณะมีงานค้างโดยไม่ตรวจสอบ

```powershell
$env:AR_ANDROID_TEST_LOGIN = Read-Host 'กรอกชื่อ login/email บัญชี Tailscale ของคุณ ไม่ใช่รหัสผ่าน'
node .\tools\serve-android-one-game.cjs
```

ใช้ชื่อloginที่แสดงในบัญชีTailscaleจริง ไม่ใช่ชื่อFacebook/อีเมลสมาชิกVIP เว้นแต่ว่าเป็นชื่อเดียวกันอยู่แล้ว ค่าจะอยู่ในหน่วยความจำของsessionนี้ เครื่องมือไม่พิมพ์ค่านั้นในlog ต้องเห็นข้อความ `One-game backend ready on 127.0.0.1:8096`

คงหน้าต่างนี้ไว้ ถ้าแจ้งพอร์ต8096ถูกใช้ ให้หยุดและตรวจ อย่าเปิดServeไปยังบริการอื่น ไม่ต้องเปิดFirewallให้พอร์ตนี้ เซิร์ฟเวอร์รับเฉพาะloopback การเปิด `http://127.0.0.1:8096` ตรงๆได้403เป็นพฤติกรรมปกติ เพราะไม่ได้ผ่านidentityของServe

มี helper `tools/start-android-one-game.ps1` ให้เลือกใช้ได้ในเครื่องที่อนุญาตรันPowerShell scriptsอยู่แล้ว หากscriptsถูกนโยบายองค์กรปิด ให้ใช้คำสั่งทีละบรรทัดข้างต้น ไม่ต้องเปลี่ยนExecution Policy

## 3. สร้าง HTTPS URL — หน้าต่างที่2

เปิดPowerShellอีกหน้าต่าง:

```powershell
& "$env:ProgramFiles\Tailscale\tailscale.exe" status
& "$env:ProgramFiles\Tailscale\tailscale.exe" serve status
```

ต้องลงชื่อเข้าและเห็นอุปกรณ์ของคุณ ถ้ามีServeบริการอื่นบน443อยู่แล้ว อย่าเขียนทับหรือสั่งresetทั้งชุด ให้ตรวจบริการเดิมก่อน รอบเตรียมนี้ไม่ได้เปลี่ยนบริการTailscaleใดๆ

```powershell
& "$env:ProgramFiles\Tailscale\tailscale.exe" serve --https=443 http://127.0.0.1:8096
```

ใช้โหมดforegroundตามคำสั่ง **ไม่ใส่ `--bg` และไม่ใช้คำสั่ง Funnel** หากTailscaleแสดงลิงก์ตั้งค่าHTTPSให้เปิดด้วยบัญชีของคุณ และเปิดHTTPS/MagicDNSที่จำเป็นสำหรับServe ไม่เปิดpublic Funnel เมื่อสำเร็จควรเห็นข้อความว่าเข้าถึงภายในtailnetและURLรูปแบบนี้:

```text
Available within your tailnet:
https://ar-test-pc.tailxxxx.ts.net
```

นี่เป็นตัวอย่างชื่อ ไม่ใช่URLที่เปิดได้จริง ให้คัดลอกURLที่คำสั่งบนเครื่องคุณแสดง คงหน้าต่างนี้ไว้ ถ้าเห็นว่าเปิดสาธารณะ/Available on the internet ให้กดCtrl+Cและหยุด ไม่ใช้URLนั้นกับงานนี้

## 4. เปิดบน Android

1. ตรวจTailscaleบนWindowsและAndroidว่ายังเชื่อมต่ออยู่ และPCไม่sleep ไม่จำเป็นต้องอยู่Wi-Fiเดียวกันถ้าTailscaleเชื่อมต่อสำเร็จ
2. นำURLHTTPSจากหน้าต่างที่2ไปเปิดใน**ChromeบนAndroid** ใช้ชื่อเต็ม `.ts.net` ไม่ใช้IP, HTTPหรือlocalhostของมือถือ
3. ต้องเห็น AR Word Quest โดยไม่มีหน้าสมาชิกหรือAdmin ถ้าได้403 ให้ตรวจชื่อloginที่กรอกกับบัญชีTailscaleทั้งสองเครื่อง ต้องตรงกัน ตรวจว่าอุปกรณ์ไม่ได้tagged ไม่แก้ด้วยการนำidentity checkออก
4. Chromeต้องแสดงการเชื่อมต่อHTTPSปกติ ถ้าcertificateไม่ผ่านให้หยุดตรวจเวลาเครื่อง/การตั้งค่าHTTPS ไม่กดข้ามcertificate warning
5. เพิ่มเสียงMediaของมือถือ กดเริ่มเกมด้วยตัวเอง แล้วอนุญาต**กล้อง**เมื่อChromeถาม เกมไม่ขอไมโครโฟน รอโหลดระบบมือครั้งแรกตามความเร็วอินเทอร์เน็ต
6. เห็นภาพกล้องและข้อความชูนิ้วชี้แล้ว ให้ชูนิ้วชี้ตามคำแนะนำ เลื่อนไปยังภาพคำตอบและค้างครู่หนึ่ง ตรวจตัวชี้/แถบค้างและการตอบ ถ้าต้องทดสอบสำรองให้แตะคำตอบ/กล่องด้วยนิ้วบนหน้าจอ

## 5. เช็กลิสต์รอบแรก — ยังไม่ทำเครื่องหมายว่าผ่านจนลองจริง

บันทึกรุ่นมือถือ Androidเวอร์ชัน Chromeเวอร์ชัน วันที่/เวลา และURLเฉพาะในบันทึกส่วนตัว ใช้ `ANDROID-REAL-DEVICE-CHECKLIST.csv`

- เปิดHTTPSและเกมได้โดยไม่เห็นข้อมูลสมาชิกหรือAdmin
- อนุญาตกล้องแล้วเห็นภาพจริง โหลดมือสำเร็จ ชี้ค้างตอบได้อย่างน้อย5ครั้ง ตรวจมือหาย/กลับมาและตอบผิดด้วย
- ฟังเสียงตอบถูก ตอบผิด รับเหรียญ และทดลองปุ่มปิด/เปิดเสียง ต้องแตะเริ่มเกมก่อนตามข้อจำกัดautoplay
- เล่นครบ20ข้ออย่างน้อยหนึ่งรอบ ตรวจจำนวนตอบถูก เหรียญ/ของพิเศษและหน้าสรุป ไม่คาดหมายเหรียญรวมตายตัวเพราะมีโบนัสสุ่ม ตอบผิดเหรียญลด1แต่ไม่ต่ำกว่า0
- ทดสอบรับกล่อง3ครั้งและของพิเศษเมื่อตอบถูก3ข้อติด ตามกลไกเดิม ตรวจเล่นซ้ำ/กลับหน้าแรก
- หมุนแนวตั้ง/แนวนอน ตรวจปุ่มไม่ล้น กดพัก/เล่นต่อ สลับแอปแล้วกลับมา เกมเดิมมีการพักอัตโนมัติ ต้องกดเล่นต่อ
- ทดสอบปฏิเสธกล้องแยกอีกรอบ แล้วแตะเล่นได้ จากนั้นคืนสิทธิ์กล้องในChrome Site settingsก่อนทดสอบมือใหม่
- ปิดTailscaleบนAndroidชั่วคราวแล้ว**reload/เปิดใหม่** ต้องเข้าURLไม่ได้ หน้าเดิมที่โหลดไว้แล้วอาจยังทำงานในหน่วยความจำ จึงอย่าตัดสินจากหน้าเดิม
- การลอง `/membership-admin.html`, `/editor.html`, `/js/membership-config.js`, `/.env`, `/.git/config` ใต้URLนี้ต้องได้404 ไม่เห็นเนื้อหา ลองด้วยบัญชีอื่นต้องถูกปฏิเสธ ไม่ต้องกรอกรหัสผ่านสมาชิกจริงใดๆ

รอบนี้ไม่ได้ยืนยันว่าเกมจะหยุดกล้องทันทีเมื่อกดหน้าแรก กลไกเกมเดิมอาจคงstreamไว้ ให้บันทึกผลและ **ปิดแท็บเกมจริงหลังจบ** แล้วตรวจสัญลักษณ์กล้องAndroidดับ ห้ามสรุปว่าปิดกล้องผ่านหากยังไม่ได้ตรวจ

## 6. ปิดเมื่อเสร็จ

1. ปิดแท็บเกมบนAndroid ตรวจกล้องหยุด
2. หน้าต่างที่2กดCtrl+Cเพื่อหยุดServe (ไม่ได้ใช้โหมดbackground) ตรวจ:

```powershell
& "$env:ProgramFiles\Tailscale\tailscale.exe" serve status
```

ถ้าบริการทดสอบ443ยังอยู่ และตรวจแล้วว่าเป้าหมายคือ8096ของรอบนี้เท่านั้น:

```powershell
& "$env:ProgramFiles\Tailscale\tailscale.exe" serve --https=443 off
```

อย่าสั่งreset/ปิดบริการอื่นที่คุณใช้อยู่

3. หน้าต่างที่1กดCtrl+C แล้วล้างตัวแปร:

```powershell
Remove-Item Env:AR_ANDROID_TEST_LOGIN -ErrorAction SilentlyContinue
```

4. เปิดURLใหม่บนAndroidต้องเข้าไม่ได้ ปิดVPNTailscaleเมื่อไม่ใช้ตามต้องการ ไม่มีข้อมูลหรือรหัสผ่านFirebaseที่ต้องล้าง เพราะเครื่องมือไม่ใช้Firebaseเลย
