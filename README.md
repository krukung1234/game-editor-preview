# Krukung Game Hub — ปรับแต่ง AR Mini City

ทำงานในสำเนา repository `https://github.com/krukung1234/game-editor-preview.git` เท่านั้น บน branch `development/mini-city-editor` ฐาน commit `916eef8` ไม่มี commit, push, merge, deploy หรือเขียน Firebase/Firestore และไม่ได้แก้เว็บไซต์หลัก

## ใช้งานอย่างไร

1. เปิด Hub ผ่าน localhost หรือ HTTPS และเข้าสู่ VIP ตามเดิม
2. บนการ์ด AR Mini City กด **⚙️ ปรับแต่งเกม** เกมอื่นแสดง “ยังไม่รองรับการปรับแต่ง” โดยปุ่ม Prompt และเล่นเกมยังใช้ได้
3. เปลี่ยนชื่อ วิชา ชั้น หัวข้อ คำแนะนำ คำชม และภาพหน้าปก
4. เลือกด่านจากแท็บ แล้วเพิ่ม แก้ไข ลบ หรือเลื่อนคำถามขึ้น/ลง กำหนดตัวเลือกและเฉลย อัปโหลดหรือลบภาพของคำถาม/ตัวเลือก
5. กด **ดูตัวอย่างข้อมูล** เพื่อตรวจข้อความ ตัวเลือก เฉลย และกติกางบ จากนั้นกด **ทดลองเล่น** ระบบบันทึกฉบับนี้ในเบราว์เซอร์แล้วเปิดไฟล์เกมต้นฉบับโดยตรงพร้อมข้อมูลใหม่ ไม่ใช้ iframe แสดงข้อมูลแทนเกม ไม่เรียก AI และไม่ต้อง deploy ใหม่ทุกครั้งที่แก้ข้อมูล
6. กลับด้วยลิงก์ “กลับหน้าหลัก / ปรับแต่ง” แล้วเปิดตัวแก้ไขอีกครั้งเพื่อแก้ฉบับที่บันทึกไว้

ตัวแก้ไขเก็บหนึ่งฉบับล่าสุดต่อ Adapter ในเบราว์เซอร์ ข้อมูลไม่ส่งไปกับลิงก์ หากใช้เครื่องอื่น ให้ส่งออก JSON แล้วนำเข้าในเบราว์เซอร์ปลายทางที่เปิดเว็บไซต์รุ่นนี้ การนำเข้าและคืนค่าต้นฉบับเปลี่ยนฉบับที่กำลังแก้ ต้องกดบันทึกหรือทดลองเล่นเพื่อเก็บทับฉบับปรับแต่ง ไม่เขียนทับเกมต้นฉบับ

รูปอัปโหลดรองรับ PNG/JPEG/WebP/GIF ไม่เกิน 750 KB ต่อรูป ข้อมูลรวมไม่เกิน 4 MB มีข้อความแจ้งเมื่อพื้นที่เบราว์เซอร์เต็ม ควรส่งออก JSON สำรองก่อนล้างข้อมูลเว็บไซต์

## กติกาที่คงจากเกมเดิม

ข้อมูลต้นฉบับดึงจากโค้ด Mini City จริง: 20 ภารกิจใน 5 ด่าน ไม่ได้สร้างชุดเกมใหม่ทดแทน

| ด่าน | การปรับแต่งและคะแนน |
|---|---|
| แยกสินค้า/บริการ | เปลี่ยนคำถาม รูป ชื่อสองกลุ่ม และกลุ่มที่ถูก • ถูก 1 คะแนน |
| จับคู่ | เปลี่ยนคำถาม ภาพ ตัวเลือก 2–6 ข้อ และเฉลย 1 ข้อ • ถูก 1 คะแนน |
| จัดกระเป๋า | ตัวเลือก 6 ชิ้น เลือกคำตอบถูก 3 ชิ้น • ถูกชิ้นละ 1 คะแนน |
| ซื้อของตามรายการ | 6 ชิ้น เลือก 3 ชิ้น • ถูกชิ้นละ 1 คะแนน |
| ซื้อของตามงบ | เปลี่ยนราคาและงบ เลือก 3 ชิ้น • ไม่เกินงบได้ 3 เกินงบได้ 0 |
| วางแผนซื้อของ | เหลือ 0–2 บาทได้ 3, เหลือ 3–5 ได้ 2, เหลือมากกว่า 5 ได้ 1, เกินงบได้ 0 |
| ช่วยเมือง | เพิ่ม/ลบจุดได้ 1–6 จุด ตัวเลือก 2–6 ข้อต่อจุด เฉลย 1 ข้อ • ถูก 1 คะแนน |

คงการปลดล็อกด่าน ดาว เสียง เอฟเฟกต์ กล้อง การชี้นิ้วค้าง 3 วินาที และการตรวจคำตอบของเกมเดิม ปรับเพียงการแสดงตัวเลขคะแนนด่านช่วยเมืองให้ตรงกับคะแนนจริงที่เกมคำนวณแล้ว จัดเรียงภารกิจตามที่ผู้ใช้ตั้งไว้ ตัวเลือกบางด่านยังสุ่มตำแหน่งตามกลไกเดิม

## ไฟล์อัปเดต 9 ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โหลดโมดูล Editor/Adapter และ JS/CSS รุ่นใหม่ |
| `js/app.js` | ปุ่มปรับแต่งเฉพาะการ์ดที่มี Adapter และสถานะเกมที่ยังไม่รองรับ |
| `css/style.css` | จัดปุ่มและหน้าต่างตัวแก้ไข รองรับมือถือ/แท็บเล็ต/คอมพิวเตอร์ |
| `js/game-editor.js` | ฟอร์ม จัดการคำถาม ภาพ ตัวอย่าง localStorage และ JSON |
| `js/game-adapters.js` | Registry/สัญญาข้อมูล Adapter, ตรวจข้อมูล และพื้นที่เก็บฉบับปรับแต่ง |
| `js/adapters/mini-city-defaults.json` | ข้อมูลต้นฉบับที่ถอดจากโค้ดเกมจริง |
| `js/adapters/mini-city-runtime.js` | แปลงข้อมูลเข้าโครงสร้างเดิม และเชื่อมกับ renderer/คำตอบ/คะแนนจริง |
| `css/mini-city-editor-play.css` | หน้าจอเล่นฉบับปรับแต่งบนมือถือ โหลดเฉพาะเมื่อใช้ Editor |
| `games/AR mini city/index.html` | เพิ่มจุดเชื่อม Adapter ที่ชัดเจนและให้ตัวค้นหาสินค้ารับข้อมูลจาก Adapter ได้ |

ไม่มีการแทนข้อความสุ่มในไฟล์ HTML ระหว่างเล่น Adapter ใช้รหัสข้อมูลภายในและ DOM text nodes เพื่อให้ข้อความที่มีสัญลักษณ์ HTML แสดงเป็นข้อความอย่างปลอดภัย การแก้ครั้งต่อไปทำผ่านข้อมูล JSON โดยไม่แก้โค้ดเกมซ้ำ

เกมอื่นในอนาคตต้องมี Adapter แยก โดยลงทะเบียนผ่าน `GameAdapters.register()` พร้อมตัวระบุเกม ตัวตรวจ schema ค่าเริ่มต้น และสะพานเชื่อม renderer/scoring ของเกมนั้น ห้ามจับคู่ Adapter จากชื่อการ์ดอย่างเดียว Mini City รุ่นนี้ตรวจจาก folder/URL ของไฟล์เกมจริง

## พื้นที่เก็บข้อมูล

- ฉบับที่บันทึก: `krukung.editor.v1.mini-city`
- ข้อมูลสำหรับทดลองเล่น: `krukung.editor.run.v1.mini-city`
- ความคืบหน้าระหว่างทดลองเล่น: `krukung.editor.run.v1.mini-city.progress`
- ไม่เขียนทับ `arMiniCityState` ของเกมต้นฉบับ
- เล่นต้นฉบับจากปุ่มเดิมจะไม่ใช้ข้อมูลปรับแต่ง ต้องเข้าผ่าน “ทดลองเล่น” จึงจะใช้ฉบับใหม่

หากจะเพิ่มแชร์ผ่านลิงก์จริง ต้องออกแบบที่เก็บข้อมูลและสิทธิ์เข้าถึงแยกก่อน รุ่นนี้ใช้การส่งไฟล์ JSON ข้ามเครื่องเท่านั้น

## ผลทดสอบ

Chrome headless ผ่าน localhost; จำลองข้อมูล Firestore 31 เกมโดยไม่เข้าถึงข้อมูลจริง:

- ผ่านการเพิ่ม/แก้/ลบ/เรียงคำถาม เปลี่ยนเฉลย อัปโหลดภาพหน้าปก/คำถาม การดูตัวอย่าง และแสดงข้อความที่มี `<script>` เป็นข้อความ ไม่ทำงานเป็น HTML
- ส่งออกแล้วนำเข้า JSON กลับได้ ข้อมูลผิด schema ถูกปฏิเสธโดยไม่เปลี่ยนข้อมูลที่บันทึกไว้
- บันทึกฉบับล่าสุด เปิดกลับมาแก้ได้ คืนค่าได้ และกรณี localStorage เต็มแสดงข้อผิดพลาด
- เล่นด้วยข้อมูลใหม่จริงครบ 5 ด่าน ทั้งจอคอมพิวเตอร์และมือถือแนวตั้ง
- รอบตอบถูก/ผิดบนคอมพิวเตอร์ได้คะแนนตรงคาด: แยก 1/2, จับคู่ 1/2, จัดกระเป๋า 2/3, ซื้อของรวม 4/9, ช่วยเมือง 1/2 และตรวจเฉลยที่แสดง
- รอบมือถือได้คะแนนตามกติกาเช่นกัน: จัดกระเป๋า 3/3 และซื้อของรวม 8/9 ตรวจว่าภาพตัวเลือกโหลดสำเร็จ
- ตรวจจอ 375×812, 768×1024 และ 1440×1000 ตัวแก้ไขไม่ล้นแนวนอน
- ทดสอบกล้องถูกปฏิเสธ, เปิด/ปิดกล้องจำลอง และส่งตำแหน่งนิ้วจำลองเข้าตัวรับ Hand Tracking เดิมค้าง 3 วินาที เลือกคำตอบและได้คะแนนจริง
- ทดสอบระบบ Prompt เดิมซ้ำ: สร้างข้อความ คัดลอกจริง Clipboard API และ fallback, เปิด/ปิดด้วยปุ่ม/Escape/พื้นหลัง, focus และ versioned assets ผ่าน
- VIP รหัสผิด/ถูก การจำ login/logout ค้นหา หมวดหมู่ และลิงก์เล่นเกม/Admin ผ่านชุดทดสอบเดิม
- JavaScript/console errors = 0 และ external writes = 0
- ตรวจ syntax ของ JavaScript ใหม่และ inline script ของ Mini City ผ่าน; `git diff --check` ผ่าน
- `git diff` ใน `games/` เปลี่ยนเฉพาะ Mini City เกมอื่น 30 โฟลเดอร์ไม่เปลี่ยน; `js/admin.js`, `js/config.js`, `admin.html`, `game-player.html` ไม่เปลี่ยน
- ตรวจว่าความคืบหน้าเดิม `arMiniCityState` ไม่เปลี่ยน และเล่นเกมต้นฉบับโดยตรงไม่เปิดโหมดปรับแต่ง

ข้อจำกัด: ทดสอบมือถือด้วย viewport จำลอง กล้องและผลการตรวจมือเป็นข้อมูลจำลอง ไม่ยืนยันประสิทธิภาพกล้องจริง/MediaPipe บนอุปกรณ์จริง ไม่ได้เล่นภายในเกมอื่นทั้ง 30 เกมหรือเขียนข้อมูลผ่าน Admin และยังไม่ได้ deploy

## Commit/Push ด้วยตนเองเมื่อพร้อม

คำสั่งด้านล่างเป็นคู่มือ ไม่ได้ดำเนินการให้อัตโนมัติ:

```powershell
git remote -v
git branch --show-current
git status --short
git diff --check
git diff --stat
git add -- index.html js/app.js css/style.css css/mini-city-editor-play.css js/game-editor.js js/game-adapters.js js/adapters/mini-city-defaults.json js/adapters/mini-city-runtime.js "games/AR mini city/index.html"
git commit -m "Add local Mini City editor with native game adapter"
git push -u origin development/mini-city-editor
```

ถ้าใช้ checkout เดิมของคุณแทนสำเนาที่ส่งให้ ให้สร้าง branch พัฒนาเองก่อนคัดลอกไฟล์ หาก GitHub Pages ยังเผยแพร่จาก main การ push branch พัฒนาจะยังไม่เปลี่ยนหน้าออนไลน์ ต้องตรวจ/เลือกขั้นตอนเผยแพร่ใน repository preview เอง
