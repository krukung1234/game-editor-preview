# Prompt รุ่น reference-v2

## สาเหตุที่แก้

รุ่นก่อนเปลี่ยนคำสั่งหลักแล้ว แต่ยังนำ Prompt จาก Firestore มาต่อทั้งข้อความ ทำให้ประโยคเก่า เช่น ให้ขอโค้ดก่อนลงมือ ยังติดไปในข้อความที่คัดลอก รุ่นนี้ปรับประโยคที่ขัดแย้งเฉพาะสำเนาที่นำไปใช้ ไม่แก้ record ใน Firestore

## ไฟล์เว็บไซต์ที่เปลี่ยน

- js/app.js: เพิ่ม preparePromptReference เป็นฟังก์ชันกลางสำหรับปรับเงื่อนไขขอไฟล์ในข้อความอ้างอิงและรายละเอียดผู้ใช้ ปรับคำสั่งหลักให้สร้างเกมใหม่ตามข้อกำหนดทันที ไม่รอ index.html/ZIP และแยกจากการแก้โค้ดจริง ไม่อ้างความเหมือน 100%
- index.html: เปลี่ยนป้ายรุ่นและ query app.js เป็น prompt-20261017-reference-v2 เพื่อเลี่ยงแคชเดิม

เทียบกับ Repository ทดลองรุ่นล่าสุด 4337b94618d6105b4618e477c39ab22637a34dd8 แล้ว โค้ด app.js นอกส่วนสร้าง Prompt/ฟังก์ชันปรับข้อความตรงกัน ไม่มีการเปลี่ยนไฟล์ Editor ในชุดนี้ ไม่มี Commit, Push หรือ Deploy อัตโนมัติ

## ข้อจำกัดตามจริง

ทดสอบตัวสร้างข้อความด้วยข้อมูล Firestore จำลอง 31 รายการ ไม่ได้อ่านตรวจ Prompt จริงทั้งหมดในฐานข้อมูลออนไลน์ และไม่เขียนฐานข้อมูลจริง ตัวปรับข้อความครอบคลุมรูปแบบคำสั่งที่ระบุและทดสอบไว้ ไม่ใช่ระบบเข้าใจภาษาทุกสำนวน

ไม่ได้ส่ง Prompt ไปทดสอบให้ AI ภายนอกสร้างเกมจริงครบทุกเกม ไม่รับรองว่า AI ทุกตัวจะทำตามเสมอหรือรักษาโค้ดเดิมได้ 100% เมื่อมีเพียง Prompt ไม่มีการอ้างว่าทดสอบกล้อง AR หรือ Hand Tracking ของเกมที่ AI จะสร้าง ตัวอย่าง Word Quest ในชุดนี้ใช้ข้อมูลอ้างอิงจำลองตามเกณฑ์ที่ผู้ใช้กำหนด

## วิธีใช้ชุดอัปเดต

1. เปิดเฉพาะ Repository game-editor-preview และใช้ branch ทดลอง
2. สำรองแล้ววาง index.html ที่ราก Repository และ js/app.js ในโฟลเดอร์ js/ แทนที่เฉพาะสองไฟล์นี้ อย่าแทนที่ทั้งเว็บไซต์
3. ชุดนี้ไม่รวมไฟล์พัฒนาระบบ Editor ที่ค้างจากงานก่อนหน้า
4. ตรวจ diff และทดสอบก่อน Commit/Push ด้วยตนเอง หากไฟล์ในเครื่องเปลี่ยนเพิ่มเติมแล้ว ให้ใช้ prompt-only.patch เพื่อตรวจและปรับเฉพาะส่วนแทนการทับทั้งไฟล์
5. หลังเผยแพร่บน GitHub Pages ของ Repository ทดลอง กด Ctrl+F5 และตรวจป้าย Prompt รุ่น 20261017-reference-v2
