# Game Hub — ปุ่ม 3 ตำแหน่งและตัวแก้ไขเกม

แก้จากโค้ดล่าสุดของ `krukung1234/game-editor-preview` commit `13c609d` ในสำเนา `game-editor-preview-current` บน branch `development/card-editor-fix` ไม่แก้เว็บไซต์หลัก ไม่เขียน Firebase/Firestore และไม่ได้ commit, push, merge หรือ deploy

## ผลตรวจปัญหา

ในภาพผู้ใช้ยังมี Prompt/เล่นเกมสองปุ่ม ขณะที่ HTML และ app.js ออนไลน์ที่อ่านระหว่างตรวจครั้งนี้มีโมดูล Editor และคำสั่งสร้างปุ่มแล้ว จึงไม่ยืนยันว่าเกิดจาก cache เพียงอย่างเดียว โค้ดรุ่นก่อนยังมี CSS สองชุดกำหนดจำนวนคอลัมน์ขัดกัน ปุ่มเล่นเกมถูกขยายเป็นอีกแถว และใช้ข้อความแทนปุ่มสำหรับเกมที่ไม่มี Adapter

แก้ให้การ์ดทุกเกมมี 3 ปุ่มตามลำดับ **📋 Prompt → ⚙️ ปรับแต่งเกม → ▶ เล่นเกม** อยู่ในแถวเดียวกัน ปุ่มปรับแต่งตรงกลางเปิดได้เฉพาะ Mini City เกมที่ยังไม่รองรับปิดปุ่มและแสดงข้อความใต้ปุ่ม เกมที่ไม่มี Prompt ปิดเฉพาะปุ่ม Prompt พร้อมคำอธิบาย ไม่แสดงว่าฟังก์ชันนั้นพร้อมใช้

หาก Editor โหลดไม่สำเร็จ ทุกการ์ดยังแสดงปุ่มกลางที่ปิดไว้พร้อมข้อความให้รีเฟรช โดยไม่ทำให้การ์ดหรือระบบ Prompt/เล่นเกมหาย

## ฟังก์ชันที่ใช้งานได้

- AR Mini City: เปลี่ยนชื่อ วิชา ชั้น หัวข้อ **คำอธิบายเกม** คำแนะนำ คำชม ภาพหน้าปก ภาพคำถาม และภาพตัวเลือก
- เพิ่ม/แก้ไข/ลบ/เรียงคำถาม เปลี่ยนตัวเลือกและเฉลย
- ดูข้อมูลก่อนเล่น แล้วทดลองเล่นผ่านไฟล์ Mini City เดิมจริง คงมินิเกมทั้ง 5 แบบ คะแนน การเฉลย AR/การชี้ค้าง เสียง และเอฟเฟกต์เดิม
- บันทึกฉบับปรับแต่งในเบราว์เซอร์ นำเข้า/ส่งออก JSON และคืนค่าต้นฉบับ ข้อมูล JSON รุ่นก่อนที่ยังไม่มี description ยังอ่านได้
- คำอธิบายใหม่แสดงในตัวอย่างข้อมูลและหน้าเริ่มเกมฉบับปรับแต่ง ไม่แก้ชื่อหรือคำอธิบายการ์ดต้นฉบับใน Firestore
- ปุ่มเล่นเกมเดิมเปิดต้นฉบับ ปุ่มทดลองเล่นใช้ฉบับปรับแต่ง ไม่ใช้ iframe แสดงเพียงข้อมูลแทนการเล่น

ข้อจำกัดจากกติกาเดิมยังคงอยู่: แยกสินค้า/บริการมี 2 กลุ่ม จัดกระเป๋าและซื้อของมี 6 ตัวเลือก/เลือก 3 ชิ้น แผนที่ช่วยเมืองมีสูงสุด 6 จุด โหมดซื้อของตามงบ/วางแผนคำนวณเฉลยจากราคาและงบ ไม่ใช้ช่องติ๊กเฉลยแบบข้อสอบ

localStorage ไม่ส่งข้อมูลข้ามเครื่อง ให้ส่งออก JSON แล้วนำเข้าในเบราว์เซอร์ปลายทาง รูปอัปโหลดรองรับ PNG/JPEG/WebP/GIF ขนาดไม่เกิน 750 KB ต่อรูปและข้อมูลรวมไม่เกิน 4 MB

## ผลทดสอบ

ทดสอบ Chrome headless ผ่าน localhost ใช้การ์ดจากชื่อและเส้นทางโฟลเดอร์เกมจริง 31 โฟลเดอร์ พร้อมข้อมูล Firestore จำลอง ไม่อ่านหรือเขียนฐานข้อมูลจริง:

1. ทุกการ์ดมีปุ่ม 3 ปุ่มตามลำดับ จำนวนตรง: Editor เปิดใช้ 1 ปุ่ม ปิดใช้ 30 ปุ่ม และมีเหตุผลแสดงใต้ปุ่ม
2. ตรวจตำแหน่งและการไม่ล้นการ์ดที่ความกว้าง 375, 768, 1024, 1280 และ 1440 px ปุ่มทั้งสามอยู่ในแถวเดียวกัน
3. คลิกปุ่ม disabled แล้วไม่เปิดหน้าต่าง และจำลองโมดูล Editor หายแล้วปุ่มทั้งหมดปิดอย่างชัดเจน
4. เพิ่ม/แก้/ลบ/เรียงคำถาม เปลี่ยนเฉลย อัปโหลดภาพ แก้คำอธิบาย บันทึก ส่งออก JSON นำเข้ากลับ และเล่นจริงได้
5. JSON ผิด schema ถูกปฏิเสธโดยไม่เปลี่ยนข้อมูลที่บันทึกไว้ จำลองพื้นที่เก็บเต็มแล้วมีข้อความแจ้ง คืนค่าต้นฉบับได้
6. ใช้ข้อความที่มีสัญลักษณ์ HTML เป็นข้อความ ไม่ทำงานเป็นโค้ด
7. เล่นครบทั้ง 5 มินิเกมของ Mini City บนจอคอมพิวเตอร์และมือถือจำลอง ตรวจทั้งคำตอบถูกและผิด: คอมพิวเตอร์ได้ 1/2, 1/2, 2/3, 4/9, 1/2 ตามที่ตั้งโจทย์; บนมือถือจัดกระเป๋าได้ 3/3 และซื้อของได้ 8/9 ตามกติกา
8. คำอธิบายใหม่ไปถึง JSON และหน้าเริ่มเกมจริง ภาพตัวเลือกบนมือถือโหลดสำเร็จ
9. ทดสอบกล้องถูกปฏิเสธ กล้องจำลองเปิด/ปิด และตำแหน่งนิ้วจำลองค้าง 3 วินาทีผ่านตัวรับ Hand Tracking เดิม เลือกคำตอบได้จริง
10. ระบบ Prompt เดิมสร้างข้อความ/คัดลอกผ่าน Clipboard API และ fallback ได้ เปิด–ปิดด้วยปุ่ม/Escape/พื้นหลังและคืน focus ผ่าน
11. VIP รหัสผิด/ถูก จำการล็อกอิน ออกจากระบบ ค้นหา หมวดหมู่ ลิงก์เล่นเกม/Admin และ URL asset รุ่นใหม่ผ่านชุดทดสอบ
12. JavaScript/console error = 0; external writes = 0; syntax และ `git diff --check` ผ่าน ไม่มีการเขียนความคืบหน้าทับ `arMiniCityState`

ข้อจำกัด: มือถือทดสอบด้วย viewport จำลอง กล้องและตำแหน่งมือเป็นข้อมูลจำลอง ไม่ใช่กล้อง/MediaPipe บนอุปกรณ์จริง เกมอื่น 30 เกมตรวจการ์ด เส้นทางไฟล์ และสถานะการรองรับเท่านั้น **ยังไม่ได้ทดสอบแก้ไข/เล่นเนื้อหาใหม่ภายในเกมเหล่านั้น** และยังไม่เปิดใช้ Editor ให้เกมเหล่านั้น

## นำขึ้น GitHub Pages ด้วยตนเอง

### เตรียมไฟล์และ branch

1. แตก ZIP แล้วคัดลอกไฟล์ภายในไปเพิ่ม/แทนตามโครงสร้างเดิมของ **game-editor-preview** ทั้ง 9 ไฟล์ ไม่ใช่อัปโหลด ZIP เป็นหน้าเว็บไซต์
2. ทำบน branch พัฒนา เช่น `development/card-editor-fix` ตรวจ remote ต้องเป็น `krukung1234/game-editor-preview.git`
3. ถ้าใช้สำเนาที่ส่งให้ branch นี้สร้างไว้แล้ว หากใช้ clone ของตนเอง ให้สร้าง branch จากโค้ดล่าสุดก่อนคัดลอกไฟล์

```powershell
git remote -v
git branch --show-current
git diff --check
git diff --stat
git add -- index.html css/style.css js/app.js js/game-adapters.js js/game-editor.js js/adapters/mini-city-runtime.js "games/AR mini city/index.html"
git commit -m "Fix three-button game cards and complete Mini City description editor"
git push -u origin development/card-editor-fix
```

คำสั่ง commit/push ข้างต้นเป็นขั้นตอนให้คุณดำเนินการเอง ไม่ได้รันให้อัตโนมัติ ถ้าใช้ GitHub ผ่านเว็บ ให้เลือก branch พัฒนาใน repository preview แล้วใช้ Add file → Upload files โดยรักษาโฟลเดอร์ `js`, `css`, `games/AR mini city` ให้ถูกตำแหน่ง

### เลือกแหล่งเผยแพร่ให้ตรง

ใน repository **game-editor-preview** เปิด Settings → Pages ตรวจ Source:

- ถ้าใช้ **Deploy from a branch** ให้เลือก branch และโฟลเดอร์ที่มีไฟล์รุ่นนี้ เช่น branch พัฒนาและ `/(root)` แล้ว Save หรือเปิด PR เพื่อตรวจและ merge เองไปยัง branch ที่ Pages ใช้อยู่ **ภายใน repository preview เท่านั้น**
- ถ้าใช้ **GitHub Actions** ให้ตรวจ workflow ว่า checkout และเผยแพร่ branch ใด แล้วใช้ขั้นตอนเผยแพร่ของ workflow นั้น

การ push branch พัฒนาอย่างเดียวไม่ทำให้หน้าออนไลน์เปลี่ยน หาก Pages ยังเผยแพร่จากอีก branch รอ deployment สำเร็จใน Actions ก่อนเปิดทดสอบ แหล่งอ้างอิง: [GitHub Docs — Configure publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

เปิด https://krukung1234.github.io/game-editor-preview/?release=editor-20261016-4 กด Ctrl+Shift+R หรือใช้ Incognito ตรวจ footer และ Network ตามข้างต้น ถ้า footer ยังรุ่นเก่า ให้ตรวจ source branch/deployment และ HTML ที่ browser ได้รับก่อนสรุปว่าเป็น cache

## เกมอื่นต้องแก้เพิ่มที่ใด

ดูรายเกมและชื่อชุดข้อมูลที่ตรวจพบใน `game-compatibility-inventory.json` และตาราง `GAME-ADAPTER-COMPATIBILITY.md` ที่แนบ เป็นการสำรวจ source แบบ static ไม่ใช่การรับรองการเล่นของทุกเกม

แต่ละเกมต้องมี Adapter และ schema ของตนเอง ค่าเริ่มต้นจริง จุดเชื่อมในไฟล์เกมที่ระบุ แล้วทดสอบการแสดงคำถาม ตัวเลือก เฉลย คะแนนและกล้องก่อนเปิดปุ่ม ต้องปรับ `js/game-adapters.js` เพื่อลงทะเบียน และขยาย `js/game-editor.js` หรือ Editor เฉพาะเกมเมื่อกติกาข้อมูลต่างจาก Mini City การเพิ่มชื่อเกมลง registry อย่างเดียวไม่เพียงพอ

ไม่มีการอ้างว่า 30 เกมที่เหลือพร้อมปรับแต่ง และไม่มีปุ่มเปิดใช้ที่ทำได้เพียงแสดงตัวอย่างหน้าตา
