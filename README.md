# อัปเดตระบบ Prompt — พร้อมนำไปใช้กับ AI

แก้เฉพาะระบบ Prompt บน Repository game-editor-preview รุ่นอ้างอิง ff771fd30da1ea2f7d201f93575a0ba9343dd646 บน branch development/shared-editor-adapters ไม่ได้ Commit, Push หรือ Deploy

## ไฟล์เว็บไซต์ที่เปลี่ยน

- index.html: เปลี่ยนคำแนะนำและป้ายรุ่นของ Prompt พร้อมเปลี่ยน query ของ app.js เพื่อเลี่ยงแคชเดิม ไม่เปลี่ยนรายการไฟล์ Editor
- js/app.js: แก้เฉพาะการประกอบข้อความใน submit ของ promptForm โค้ดส่วนอื่นตรงกับ Repository รุ่นอ้างอิง ไม่แก้ Editor เล่นเกม Admin หมวดหมู่ การค้นหา หรือไฟล์เกม

## พฤติกรรมใหม่

รวม Prompt ต้นฉบับจากข้อมูล Firestore ของเกมที่คลิกไว้ครบ พร้อมข้อมูลวิชา ระดับชั้น ชื่อใหม่ หัวข้อ และรายละเอียดผู้ใช้ ไม่แก้ไขข้อมูล Firestore ตัวสร้าง Prompt กลางใช้ร่วมกับทุกเกม

สั่งส่งเกมสมบูรณ์เป็น index.html หรือ HTML เต็มใน Code Block เดียว ไม่สั่งขอโค้ดเพิ่ม ไม่หยุดแค่แผนงาน รักษากติกา จำนวนด่าน/ข้อ คะแนน โบนัส การควบคุม กล้อง เสียงและ UI ตามข้อมูลเฉพาะเกม หากผู้ใช้ไม่ได้ระบุให้เปลี่ยน พร้อมเมาส์/สัมผัสสำรอง และภาพ Emoji/CSS/SVG ตามเนื้อหา

ถ้ามีโค้ดจริงในบริบทให้ใช้เป็นฐาน หากมีเพียง Prompt ให้สร้างจากข้อกำหนดนั้นและไม่อ้างว่าแก้โค้ดจริง เพิ่มข้อสรุปหลังข้อความต้นฉบับเพื่อแก้ความขัดแย้งกรณี Prompt เก่าเคยสั่งให้ขอไฟล์

## ผลทดสอบจริง

- Chrome + Playwright: ผ่าน 31 รายการทดสอบที่จำลอง Firestore โดยใช้ชื่อโฟลเดอร์เกมจริง แต่แยก Prompt จำนวนด่าน จำนวนข้อ คะแนน และโบนัสต่างกันในแต่ละรายการ
- ผ่านโหมด AI เปิด/ปิดครบ 31 รายการ การคงข้อความต้นฉบับ ชื่อใหม่ว่างใช้ชื่อเดิม วิชาอื่น ระดับชั้น รายละเอียด และการคืนค่า/เปิดใหม่
- ผ่านคัดลอกลง Clipboard จริง วิธีสำรองเมื่อ Clipboard ถูกบล็อก และแจ้งความล้มเหลวตามจริง
- ผ่าน X, Escape, คลิกนอกหน้าต่าง และ Focus Trap
- ผ่านหน้าจอ 1440×1000, 768×1024, 375×812, 320×568 และ 844×390 ไม่มีแนวนอนล้น Header/Footer อยู่กับที่ ช่องผลลัพธ์สูง 180px
- ไม่พบ JavaScript Error ในชุดทดสอบ ไม่พบคำขอเขียนข้อมูล และรายการเกมไม่ถูกแก้ไข
- ตรวจ syntax ของ js/app.js ผ่าน และเปรียบเทียบยืนยันว่าโค้ด app.js นอกบล็อกสร้าง Prompt ตรงกับรุ่นอ้างอิง

ข้อจำกัด: ไม่ได้เขียนหรืออ่านแก้ข้อมูล Firestore จริงในการทดสอบ ใช้ฐานข้อมูลจำลอง ไม่ได้ทดสอบให้ AI ภายนอกสร้างเกมจากทุก Prompt หรือทดสอบกล้อง AR ของเกมที่ AI จะสร้าง ความใกล้เคียงขึ้นกับรายละเอียด Prompt ต้นฉบับและความสามารถของ AI ไม่รับรองว่าจะเหมือนต้นฉบับทุกจุดเมื่อไม่มีโค้ดหรือทรัพยากรเดิม

## วิธีนำไปใช้

1. ตรวจว่าเปิด Repository game-editor-preview และใช้ branch ทดลอง ไม่ใช่เว็บไซต์หลัก
2. สำรองไฟล์เดิม แล้ววาง index.html ที่ราก Repository และ js/app.js ในโฟลเดอร์ js/ โดยแทนที่เฉพาะสองไฟล์นี้ ไม่ต้องวางทับทั้งโฟลเดอร์เว็บไซต์
3. เปิดเว็บไซต์ทดสอบ ตรวจป้าย Prompt รุ่นใหม่ เลือกเกม วิชา ชั้น และหัวข้อ สร้างแล้วคัดลอกข้อความ
4. ตรวจ diff ก่อน Commit และ Push ด้วยตนเอง ไม่มีการดำเนินการสองอย่างนี้อัตโนมัติ
5. หากเผยแพร่ผ่าน GitHub Pages ให้ใช้เฉพาะ Repository ทดลองและ branch/folder ที่ตั้งใจเผยแพร่ รอ deployment สำเร็จ แล้วกด Ctrl+F5 ตรวจว่ามี query ใหม่ของ app.js
