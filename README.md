# Game Editor VIP V21 Spark

ชุดรวมเว็บไซต์เดิม ระบบสมาชิก และเกม AR 31 เกม รวม ANATOMY LAB ที่แก้ลำดับสคริปต์ในไฟล์เว็บไซต์จริงแล้ว

เริ่มจาก [คู่มือเปิดทดลองภาษาไทย](START-HERE-TH.md) และ [รายงานล่าสุด](docs/membership/RELEASE-V21-REPORT.md)

ใช้ Firebase Authentication และ Firestore บน Spark เท่านั้น Production ยังปิดไว้ ไม่มีการ Deploy, Commit หรือ Push ไม่มี Functions, Cloud Storage หรือ Gateway

Working Copy อยู่ชั่วคราว เปิด Editor ใหม่กลับเป็นต้นฉบับ ไม่บันทึกฉบับร่างถาวร สมาชิกต้องยืนยันอีเมลและได้รับอนุมัติ สิทธิ์ Admin ตั้งผ่าน Console โดยผู้ดูแลเท่านั้น

ไฟล์เกมบน GitHub Pages ยังเข้าถึงผ่าน URL ตรงได้ กล้อง/Hand Tracking และทุกด่านบนอุปกรณ์จริงยังต้องทดสอบตามเช็กลิสต์ ไม่อ้างว่าผ่านจากผลจำลอง
