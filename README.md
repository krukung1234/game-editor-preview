## ZIP มีอะไรและเปิดอย่างไร

ZIP ตัวอย่างที่ทดสอบมี **80 ไฟล์ ประมาณ 103.4 MB** ขนาดจริงขึ้นกับภาพส่วนตัว ประกอบด้วย:

- `index.html` หน้ากดเปิดเกมส่วนตัว
- `games/AR mini city/index.html` สำเนาเกมเดิม ไม่เปลี่ยนสคริปต์หลักภายใน
- `personal-game-data.js` ข้อมูลส่วนตัวสำหรับเล่น ไม่อ่าน draft จาก browser ที่สร้าง ZIP อีก
- รูปฉาก รูปสินค้า/บริการ ภาพคำถาม/ตัวเลือกและภาพอัปโหลดที่จำเป็น
- Adapter และ stylesheet ที่เกมใช้
- MediaPipe Hands **0.4.1675469240** พร้อม graph/model/WASM และ Camera Utils รวม license
- `my-game.json` สำรองข้อมูลสำหรับนำเข้า Editor เพื่อแก้ต่อ
- `PACKAGE-MANIFEST.json` รายชื่อ ขนาด และ SHA-256 ของไฟล์ที่แพ็ก
- `README-TH.txt` วิธีเปิดและข้อจำกัด

**แตก ZIP ทั้งหมดก่อน** เปิด `index.html` แล้วกดเปิดเกม เล่นด้วยคลิก/แตะได้โดยไม่เข้า Hub หรือเชื่อม Firebase

สำหรับ AR/Hand Tracking แนะนำเปิดโฟลเดอร์ผ่าน **localhost หรือ HTTPS** และอนุญาตกล้อง ไฟล์โมเดลถูกรวมมาแล้ว จึงใช้แบบออฟไลน์ผ่าน localhost ได้หลังดาวน์โหลดครบ การเปิดแบบ `file://` ทดสอบการเล่นคลิกได้ แต่บาง browser บล็อกการโหลดโมเดล/WASM จากไฟล์ จึงไม่รับรอง AR ด้วยการดับเบิลคลิกอย่างเดียว

หากมี Python อยู่แล้ว เปิด terminal ในโฟลเดอร์ที่แตกไฟล์ รัน:

```text
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000/` ขั้นตอนนี้ไม่ต้องใช้อินเทอร์เน็ต แต่ต้องมี Python ติดตั้งอยู่ กล้องต้องได้รับสิทธิ์จากผู้ใช้และอุปกรณ์ต้องรองรับ WebGL/WASM เสียงเอฟเฟกต์ใช้กลไกเดิม เสียงพูดภาษาไทยขึ้นกับ voice ที่ติดตั้งในเครื่อง ไม่รับรองทุก OS/เสียงพูดออฟไลน์ อ้างอิงเรื่องสิทธิ์กล้องและ secure context: [MDN getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)

**ขณะสร้าง ZIP ต้องใช้อินเทอร์เน็ต** เพื่ออ่านไฟล์จากเว็บไซต์และ MediaPipe แต่หลังแตก ZIP จะไม่พึ่ง CDN/GitHub/Firebase ในการเล่นที่ทดสอบ หากรูป HTTPS ภายนอกติด CORS/สิทธิ์หรือดาวน์โหลดไม่ได้ ระบบจะไม่ส่ง ZIP ที่ขาดรูป แต่แจ้งให้อัปโหลดรูปแทน มีขีดจำกัดรวม 250 MB และอุปกรณ์ต้องมีหน่วยความจำเพียงพอสำหรับแพ็กไฟล์ใน browser

JSON สำหรับสำรองยังคงรูปแบบเดิม ภาพที่อัปโหลดอยู่ใน JSON เป็น data URL ส่วนภาพจาก URL ยังเป็น URL ตามเดิม หาก URL หมดอายุให้อัปโหลดรูปจาก ZIP กลับเข้า Editor สำเนาสำหรับเล่นใน ZIP เก็บรูปที่ดาวน์โหลดมาเป็นไฟล์ภายในครบแยกต่างหาก

### ขอบเขต Read-only ที่ยืนยันได้

โค้ด Editor และตัวส่งออกใช้การอ่านไฟล์ด้วย GET ไม่ใช้ token/คำสั่งแก้ repository และไม่เรียกเขียน Firestore การทดสอบไม่ทำ write probe ต่อฐานข้อมูลจริงตามข้อห้าม

**งานนี้ไม่ได้ตรวจหรือเปลี่ยน Firestore Rules/สิทธิ์ repository ฝั่ง server** จึงไม่อ้างว่าปิดการเขียนผ่าน API โดยโปรแกรมภายนอกหรือแก้ความปลอดภัยของ Admin เดิมแล้ว หากต้องการรับรอง Read-only ในระดับสิทธิ์ส่วนกลางด้วย เจ้าของระบบต้องตรวจ Rules/permissions แยกต่างหาก การซ่อนปุ่มใน browser อย่างเดียวไม่ใช่หลักฐานว่าสิทธิ์ API ถูกปิด

## ผลทดสอบเพิ่มเติม

- Chrome contexts A/B ไม่มี storage ร่วมกัน: A บันทึกชื่อ/ชั้น/คำถาม/เฉลย/ภาพใหม่ B ยังได้ต้นฉบับ และ B บันทึกไม่เปลี่ยน A
- เรียกดู Editor หลังปิดแล้วเปิดใหม่ได้ต้นฉบับทุกครั้ง และโหลด saved variant ได้โดยสั่งผ่านเมนู
- ZIP ที่โหลดจริงผ่าน Python zipfile CRC และตรวจ SHA-256 ของทุกไฟล์ใน manifest
- เทียบสคริปต์หลัก inline ของเกมที่ดาวน์โหลดกับต้นฉบับ เท่ากันหลัง normalize เฉพาะ newline
- บล็อก network ภายนอกทั้งหมด แล้วเล่นเกมดาวน์โหลดครบ 5 มินิเกม: แยก 5/6, จับคู่ 4/5, จัดกระเป๋า 9/9, ซื้อของ 8/9, ช่วยเมือง 3/3 ตรงกับคำตอบที่ตั้งทดสอบ
- ใช้ MediaPipe SDK/model/WASM **จริง** ให้ inference อย่างน้อยหนึ่งเฟรมด้วยวิดีโอกล้องจำลอง โดยโหลดไฟล์จาก ZIP ผ่าน localhost ไม่มีคำขอออกภายนอก
- เปิดจาก file:// เริ่มเกม แสดงคำถามส่วนตัว และตอบได้คะแนนจริง
- ทดสอบ CORS GET จริงใน Chrome สำหรับ MediaPipe/license ทั้ง 13 ไฟล์ ไม่ใช่แค่ mock ว่าโหลดได้
- จำลองภาพภายนอกเข้าถึงไม่ได้: หยุดการส่งออก ไม่มี ZIP บางส่วน ข้อมูลในฟอร์มไม่หาย
- จำลอง runtime URL เก่าจาก cache: ตัวเปิดสำเนาเรียก Adapter รุ่นใหม่ ไม่เรียก runtime เก่า
- ระบบ UX เดิมผ่าน: เลือกชั้น 15 ระดับไม่เปิดไฟล์, อัปโหลดแยกช่อง, บันทึกแล้วแก้ต่อ, เมนูหลัก 3 ปุ่ม/รอง 6 รายการ, sticky header/footer, เพิ่ม/ลบ/เรียง, JSON และคืนค่า
- จอ 1440×1000, 768×1024, 375×812, 320×568, 844×390 ผ่านชุด UX เดิม; มือถือเป็น viewport จำลอง
- Prompt และ VIP เดิมผ่านชุดทดสอบซ้ำ รวม Clipboard API/fallback, Popup/focus, ค้นหา หมวดหมู่ และ versioned assets
- JavaScript errors = 0, shared write requests = 0, external requests ระหว่างเล่น ZIP = 0; syntax และ git diff --check ผ่าน
